## 🧠 The idea

J.G-TEEN turns emotional learning into an interactive experience. Instead of presenting every lesson as a static page, the platform uses **stories, choices, consequences and reflection** to encourage users to think about resilience, empathy, courage, communication and decision-making.

This makes the repository a useful demonstration of **content-driven UX, interaction design and educational technology**.

## ✨ Experience

```text
Explore a scenario
        ↓
Choose an action
        ↓
See the consequence
        ↓
Reflect on the decision
        ↓
Learn from the experience
```

## 🚀 Run locally

```bash
git clone https://github.com/vince551/joboteen.git
cd joboteen
npx serve .
```

Use a modern browser and serve the project over HTTP so asset/module loading behaves consistently.

## ♿ Product quality goals

Because the target audience is young people, future content and features should prioritize:

- Age-appropriate language and scenarios
- Accessible color contrast and keyboard navigation
- Clear consent and privacy expectations
- Minimal collection of personal information
- Safe community interactions and moderation
- No claims that the platform replaces professional counselling or emergency support
