## ✦ Concept

J.G-TEEN turns emotional intelligence into an interactive experience. Its **Mind Library** presents story-driven simulations where choices, reflection, and consequences encourage users to think about resilience, empathy, courage, and decision-making.

## ⚡ Core Experience

- 📚 30+ interactive story experiences
- 🎴 Netflix-inspired content library
- 🧠 Choice-driven simulations
- ⭐ Reflection and rating interactions
- 💬 Community feedback / reflection feed
- 🎨 Glassmorphism and cyber-inspired visual language
- 📱 Responsive experience for modern devices

## 🛠️ Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | Modern CSS3 |
| Logic | Vanilla JavaScript / ES6+ |
| Motion | CSS animations + transforms |
| Icons | Font Awesome / BoxIcons |

## 🚀 Run Locally

git clone https://github.com/vince551/joboteen.git
