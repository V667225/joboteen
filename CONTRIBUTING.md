# Contributing to J.G-TEEN

Contributions should improve the educational, emotional-learning and accessibility goals of the project.

## Before contributing

- Keep content age-appropriate and respectful.
- Avoid collecting unnecessary personal information.
- Test responsive behavior.
- Do not commit secrets or private data.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Make and test your change.
4. Open a pull request with a concise explanation.
